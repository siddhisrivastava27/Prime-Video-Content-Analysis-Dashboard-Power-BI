# Prime Video Content Analysis Dashboard | Power BI

## Project Overview

This project focuses on analyzing Amazon Prime Video's content library using Microsoft Power BI. The dashboard provides an interactive overview of movies and TV shows available on the platform, exploring content distribution, ratings, genres, countries, and release trends.

The objective is to transform raw streaming content data into meaningful visual insights that help understand Prime Video's content catalog and its growth over time.

## Key Features & Analysis

The dashboard includes the following visualizations:

- **Key Performance Indicators (KPIs):** Overview of total titles, ratings, directors, genres, and release years.
- **Content Ratings Analysis:** Distribution of titles across different age-based rating categories.
- **Genre Analysis:** Identification of the most common genres available on Prime Video.
- **Geographical Distribution:** World map showing the distribution of content by country.
- **Movies vs. TV Shows:** Comparison of movies and television shows using a donut chart.
- **Release Year Trends:** Analysis of content releases over different years.

## Key Insights

- Movies represent a larger share of the content library compared to TV shows.
- Drama and Comedy are among the most represented genres.
- Content is distributed across multiple countries, highlighting the platform's international catalog.
- Content releases show a significant increase in recent years.
- The dashboard provides an overview of the distribution of titles across different audience rating categories.
